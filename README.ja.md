# Naire

> Windows / macOS 対応の一括リネームツール。Flexible Renamer（2011 年で更新停止）の精神的後継。

[English README](./README.md)

Naire は、強力で予測可能、かつ日本語フォルダ・ファイル名操作を完全サポートした一括リネーマーをモダン OS にもたらすデスクトップアプリケーションです。正規表現・ワイルドカード・22 種類の定型処理・スクリプト可能なマクロ・連番付与、そして v1.0.0 で新搭載の **フォルダ集約** 機能（兄弟フォルダを共通プレフィックスから生成した親フォルダにまとめる）に対応します。

Tauri v2 + React + TypeScript + Rust で実装しています。

---

## 機能

### リネームエンジン

- **正規表現モード** — Rust `regex` クレート（線形時間保証・ReDoS 耐性）、キャプチャグループ、豊富な置換変数
- **ワイルドカードモード** — `?` `*` を全体マッチの正規表現に変換
- **文字変換モード** — `tr` 風 1:1 マッピング、範囲記法（`a-z`）と列挙記法（`0,i,ii,iii,...`）対応
- **22 種の定型** — 大文字小文字 / 仮名変換 / 全半角 / ダイアクリティカル除去 / **濁音・半濁音除去** / 連番付与 / 日時 / フォルダ名 / 各種削除パターン / 8.3 形式 / 数値桁合わせ・増減 / 拡張子操作
- **マクロシステム** — ステップを任意の順番で組み合わせ、ステップ単位で実行・巻き戻し可能。`\orig` 変数でマクロ開始時の元名を参照
- **マクロ JSON インポート / エクスポート** — `.json` でマクロを共有（Claude 生成も含む）

### フォルダ集約（v1.0.0 新機能）

- 兄弟フォルダを複数選択 → Naire が最長共通プレフィックスを抽出し、それを名前とする新規親フォルダを作成
- 選択フォルダを 1 操作で新規親フォルダへ移動
- オプションで連番リネームを同時適用（例: `Vol01`、`Vol02`、... → `01`、`02`、...）
- 完全な UNDO 対応: 集約操作（フォルダ作成 + 移動 + リネーム）は 1 スタックエントリとして扱われ、`Ctrl+Z` で完全復元可能

### 日本語ファイル名サポート

- ひらがな ↔ カタカナ変換（`U+3041–U+3096` ↔ `U+30A1–U+30F6`）
- 全角 ↔ 半角変換（英数字 + カタカナ）
- **濁音・半濁音除去** — NFD 正規化経由（例: `が` → `か`、`ぱ` → `は`、`ガ` → `カ`）
- ラテン文字向けのダイアクリティカルマーク除去

### 置換変数

| 変数 | 意味 |
|---|---|
| `\0` | 現在のファイル名（拡張子含む） |
| `\t` | ファイルタイトル（拡張子除く） |
| `\e` | 拡張子（先頭ドット含む） |
| `\f` | 所属フォルダ名 |
| `\F` | 親フォルダ名 |
| `\;` / `\:` | ファイルサイズ（3 桁区切りあり / なし） |
| `\Y` `\y` `\m` `\d` `\H` `\I` `\M` `\S` | ファイル mtime ベースの日時要素 |
| `\a` `\A` `\b` `\B` `\p` | ロケール依存の曜日 / 月名 / AM-PM |
| `\#X` | 直後の日時変数の先行ゼロ削除 |
| `\1`–`\9` | 正規表現キャプチャグループ |
| `\u` `\l` `\U` `\L` `\E` | 大文字小文字制御修飾子 |
| `?` `??` `???` `????` | 1–4 桁連番 |
| `\orig` | マクロ開始時点の元名（マクロ専用） |
| `\?` `\\` | リテラル `?` / `\` |

### ワークスペース機能

- **フォルダブラウザ** — エクスプローラー風ツリー（左ペイン）、macOS は `/Volumes/*`、Windows はドライブレター・マップ済みネットワークドライブを表示
  - **インラインリネーム** — フォルダ名をダブルクリックで編集（Enter で確定、Esc でキャンセル）。UNDO スタックに記録
  - **内容量表示** — 各フォルダにファイル数と合計サイズ（再帰集計）を表示。ドライブルートは性能上スキップ
  - **ペイン幅可変** — ツリーと中央パネルの境界をドラッグでリサイズ。再起動後も復元
  - **右クリック → ゴミ箱へ移動** — OS 標準のゴミ箱に送る（OS 側から復元可能）
- **表示フィルタ** — セミコロン OR グロブ（`*.jpg;*.png`）、否定（`^(*.tmp)`）、7 種類のプリセット、10 件の履歴
- **リアルタイムプレビュー** — 変更前後を並列表示、変更行はハイライト
- **行選択** — クリック / Ctrl+クリック（トグル）/ Shift+クリック（範囲）。部分選択時は選択行のみリネーム
- **カラム幅可変** — リサイズ可能・再起動後も復元
- **サブフォルダ再帰** — 深さ制御（0 = 無制限）
- **連番カウンタ** — 10 進 / 16 進 / 英大文字（bijective base-26）、フォルダごとリセットオプション
- **UNDO** — 直近 20 件、`Ctrl+Z` ショートカット
- **再読み込み** — `再読み込み` ボタンでプレビューとフォルダツリー（スタッツ含む）を一括更新
- **サポートボタン** — 検索 / 置換フィールドにコンテキスト連動で変数・文字クラス・プリセットを挿入
- **設定の永続化** — フォルダ・モード・フィルタ・履歴・連番設定・カラム幅・フォルダツリー幅・マクロライブラリ・ウィンドウ状態

## インストール

[Releases ページ](https://github.com/osprey74/Naire/releases/latest) からお使いのプラットフォーム用のインストーラをダウンロードしてください。

- **Windows**: `Naire_<version>_x64-setup.exe`（MSI インストーラ）または `Naire_<version>_x64_en-US.msi`
- **macOS**: `Naire_<version>_universal.dmg`（universal binary、Intel / Apple Silicon どちらでもネイティブ動作）

インストール後、スタートメニュー / アプリケーションフォルダから **Naire** を起動してください。

## クイックスタート

1. 左ペインのフォルダツリーから作業対象フォルダをクリックして選択
2. ツールバーの **ターゲット** スイッチで「ファイル」または「フォルダ」を選択
3. 必要に応じて **サブフォルダ再帰** を有効化
4. 中央パネルでリネームモードを選択: **定型** / **高度な** / **マクロ** / **集約**
5. リネームパラメータを設定（右ペインがリアルタイム更新）
6. 必要なら一部の行を選択（Ctrl+クリック / Shift+クリック）
7. 下部の **リネーム実行** をクリック。集約モードの場合は **集約実行**
8. `Ctrl+Z` で直前バッチを取り消し（最大 20 段）

マクロ作成の詳細ガイドは [docs/MACRO_REFERENCE.ja.md](./docs/MACRO_REFERENCE.ja.md)（日本語）または [docs/MACRO_REFERENCE.md](./docs/MACRO_REFERENCE.md)（英語）を参照してください。

## ソースからのビルド

### 前提条件

- Node.js 20+ （または Bun）
- Rust stable（`rustup`）
- Tauri のプラットフォーム別前提パッケージ — [tauri.app の prerequisites](https://tauri.app/start/prerequisites/) を参照

### 手順

```bash
# クローン
git clone https://github.com/osprey74/Naire.git
cd Naire

# JS 依存パッケージのインストール
npm install

# 開発モード（ホットリロード）
npm run tauri dev

# 本番ビルド（src-tauri/target/release/bundle/ にインストーラが生成）
npm run tauri build
```

バックエンドのテスト:

```bash
cd src-tauri
cargo test --lib
```

v1.0.0 時点で **127 件のテスト** がリネームエンジン、マクロランナー、フォルダ集約、UNDO、ファイルシステム操作をカバーしています。

## アーキテクチャ

```
src/                       # React + TypeScript フロントエンド（Vite）
├── App.tsx                # メインシェル、state オーケストレーション
├── components/            # UI コンポーネント（Toolbar、FolderTree、ModePanel、PreviewPanel、...）
└── types/rename.ts        # Rust DTO と共有する型定義

src-tauri/                 # Rust バックエンド（Tauri v2）
├── src/commands.rs        # Tauri コマンドハンドラ（DTO + I/O オーケストレーション）
├── src/filter.rs          # 表示フィルタ（globset）
├── src/macro_io.rs        # マクロ JSON 入出力
└── src/rename/
    ├── advanced.rs        # 正規表現 + ワイルドカード
    ├── builtin.rs         # 22 種の定型処理
    ├── char_convert.rs    # tr 風文字マッピング
    ├── convert.rs         # 仮名 / 全半角 / ダイアクリティカル / 濁音
    ├── group.rs           # フォルダ集約（Phase 14）
    ├── macro_runner.rs    # マクロステップ処理
    ├── sequence.rs        # 10 進 / 16 進 / 英大文字連番フォーマッタ
    ├── undo.rs            # バッチ UNDO（Rename / CreateDir op）
    └── variables.rs       # 置換変数の展開
```

アーキテクチャの基本方針: **リネームロジックはすべて Rust 側に集約**。フロントエンドはファイル名に対する文字列処理を一切行わず、パラメータをバックエンドに渡し、返ってきたプレビューを描画するだけです。

## リリースとバージョニング

Naire は [セマンティックバージョニング](https://semver.org/lang/ja/) に従います。

- **v1.1.0** (2026-05-24) — フォルダツリーの QoL 強化: インラインリネーム、内容量表示、ペイン幅可変、右クリック→ゴミ箱、再読み込み統合

最新の詳細は [`RELEASE_NOTES_v1.1.0.md`](./RELEASE_NOTES_v1.1.0.md) を参照してください。
